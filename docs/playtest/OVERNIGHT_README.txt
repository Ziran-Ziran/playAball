玩个球 · 本地完整流程预览（2026-11-03）

解压后双击 PlayABall.exe，不需安装 Godot；Windows 64 位 / Compatibility。
EXE已内嵌资源。请保留build_info.json和package_manifest.json，反馈时能定位版本。
这是普通菜单包，不包含调参面板、开发预设、实验室、评估脚本或个人生图元数据。

操作：
1. 主菜单“开始游戏”。在战斗空白处按住左键，向目标的反方向拖动，松开发射。
2. 运动中也可再次发射；基础冷却2.2秒，主球外环显示恢复。右键取消拖动。
3. 初始零伙伴；选“外包”后增加小肥鱼，最多3个。受撞后才出击，跟随/接力需对应升级。
4. 绿色/黄色/紫色数字是敌人准确剩余生命。橙色是攻击预警；红色震波和尖刺有危险。
5. 拖动不必从球上开始；按钮上松开不会误发射。Esc暂停。
6. 暂停菜单可调音效/提示音量、静音、关震动、开关可选“击破分裂”，也可重开/回主菜单。
7. 胜负后可按R或按钮重开；结算按钮可直接返回主菜单。

流程：
第1～2波：翻转挡板 → 商店 → 第3～4波：十字/移动板/局部尖刺 → 补给 → 第5波：旋转弧/传送 → 首领：内外旋转场。
挡板会被真实撞动。尖刺只伤主球，仍受共用无敌时间限制。
左右传送门保留速度和攻击链；出口被占用时会拒绝，不把球塞进墙或其他实体。
商店4币恢复2血、8币选一次成长，各限一次；补给可回血、成长或跳过。
白饭返还部分冷却并强化下一发的有效命中。击杀奖励选卡会暂停战斗。

本轮已做固定种子真实物理候选比较，失败候选未强行采用：基础冲量1050、反向抵消0、基础冷却2.2秒保留。
肥鱼/箱子/装甲位图、四卡真实收益、分级碰撞反馈、预警倒计时与首领状态已接入。球旁短青弧表示真实回能，首领倒计时只显示蓄力/破防的剩余窗口。自然难度、整体美术和声音听感仍需要真人试玩判断。
自动功能状态夹具验证过胜利界面，不等于真人自然通关；正常AI留出测试九局均在第三波死亡。

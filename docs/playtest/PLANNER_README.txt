玩个球 · 策划功能预览（2026-10-31）

这是玩法原型：目前主要看“主球弹射→撞出伙伴接力→击杀成长→阶段补给→首领”的方向。
画面、音效、难度和手感仍在调试，不代表最终品质。

启动：解压后双击 PlayABall.exe。不需要安装Godot。Windows 64位，使用Compatibility图形模式。
本文件夹的exe已内嵌游戏资源；也可直接发送exe。保留build_info.json便于反馈时定位版本。

操作：
1. 在窗口空白处按住鼠标左键，向发射方向的反方向拖动，松开发射。
2. 主球运动中也能再发射，基础恢复间隔2.2秒。右键取消拖动。
3. 小蓝鱼是伙伴，不是敌人，不能击破；初始不跟随，被撞后会出击。
4. 敌人剩余生命显示为数字：绿1、黄2～3、紫4～6；高速或升级后一次可扣多血。
5. 空心圈是敌方预警；离开对应攻击范围会取消蓄力，已发出的炮弹仍需躲避。
6. 白饭是补给，靠近会吸引主球，吃到返还部分冷却并强化下一次发射的有效命中。
7. 击杀6只第一次选升级，之后门槛递增；选卡时暂停战斗。
8. Esc暂停；暂停菜单可重新开局。死亡/胜利后按R重开。
9. 顶栏可以调音量、静音、关震动，以及勾选“击破分裂”（默认关闭）。

一局流程：
波1～2 → 商店 → 波3～4 → 补给事件 → 波5 → 首领。
商店4币回2血，8币选一次成长，各限一次，可直接继续。
事件选择回2血、免费成长或跳过。阶段继续前有3秒准备。
分裂开启时，高血量敌人可变成低一级次球，最多两代；整族只奖励一次，首领不分裂。

建议先体验：
- 不开分裂，用基础配置打到第一次升级；感受方向、冷却与伙伴作用。
- 比较满力撞单只和两三只聚集敌人的差异，留意是否容易撞停。
- 有余力再体验商店/事件、升级组合和首领。

反馈最有用的内容：
当时第几波/阶段、选择了哪些升级、是否开分裂；哪里爽、哪里难、哪里看不懂。

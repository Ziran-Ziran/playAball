玩个球 1.0.0

Windows：完整解压ZIP，运行PlayABall.exe。保留同目录menu_character_runtime，菜单Live2D需要它。无需另装Godot。
安卓：安装APK，横屏游玩。提供ARM64与ARMv7程序；模拟器验证与真机兼容性分别记录在随包构建信息。

玩法：按住战场空白处，向目标反方向拖动，松开发射。就绪瞄准时战场暂停，可以规划弹道。撞伙伴能传能出击，深代接力需要实际串联。
Windows右键取消，Esc暂停；安卓可用取消/暂停按钮与系统返回键。切到后台会取消手势并暂停，回来后主动继续。
击杀成长可用金币有限重选；不同路线与后段补给共享预算。看清当前收益和价格再选。

设置中可调整音乐/主音量、全部静音与减少动态。游戏使用《Let Me Go（共创版）》背景音乐，保留原来源署名，分发许可由项目所有者确认。

测试边界：自动测试和模拟器不替代真人自然整局、全部安卓机型兼容及长时间温升测试。具体命令、版本、构建校验和已知限制见本目录随包文件。

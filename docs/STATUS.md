## 已知限制与接手注意

- 占位几何美术、绘制亮环与合成音；没有真实灯光、正式美术和成品关卡。
- 短轨迹提示忽略阻尼、障碍和机关；目标是接触即胜利；单区域互斥模式，不支持多个重叠机关叠加。
- 目标绘图和传感器坐标需同时修改；机关外观/形状在运行时生成，下一次关卡编辑工作可优先封装可视化目标和机关。
- 现有本机 MCP 绑定了另一个 xplore 项目，因此本轮运行与验证使用直接 CLI，未修改该全局配置。后续使用 MCP 必须先确认项目路径。
- 仓库尚未授予开源许可证。所有者仍需邀请另外两位开发者的 GitHub 账号。

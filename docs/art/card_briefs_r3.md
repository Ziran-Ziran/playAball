## 生成前后都要检查什么

1. **先写本张描述**：真实效果、故事瞬间、机位、主体/道具、受力、与其他图的区别、禁止暗示。下列28项分别对应一个真实资源键，不把一个模板换ID当设计。
2. **统一画法，不锁死姿势**：同一角色的脸、服装和笔触保持；允许俯视、近景、背面、静态日常和道具主视角。不同成长要有不同叙事，同系列围绕同一主题改变动作阶段或机位。
3. **等级必须可辨**：数量型用准确数量；力度/时间型用明显动作与受力变化，不能只加几根线或换颜色。插画不承担精确数值，等级、收益、真实危险半径仍由游戏文字/逻辑表达。
4. **参考只传递身份与画法**：每次明确参考的用途，不再无条件写“保持上一等级机位、构图、主姿势不变”。输出仍为1536×1024插画区，无卡框、文字、数字、UI和水印。
5. **小图验收**：先看约167像素宽的主体轮廓、动作和焦点；遮去标题仍应能区别主题。局部小改却缩图看不出的，标记不合格，不用技术测试覆盖审美判断。
6. **小批返修**：初次先做运筹、保龄球、饱餐三张构图差别大的验证图；分别检查、保留旧图。后续用户已明确要求持续到实装，按计划012将通过语义自查的候选替换到assets/cards，生成数量继续累计，审美状态不自动通过。

## 28张逐张描述

### 重击 / heavy

- **heavy_lv1｜！？肥肥？！一级**：真实效果为有效撞击伤害+1，不改变体型或碰撞体。保留历史一级母版作为参考候选：全身侧面肩颊挤入软垫，脚跟扎地，垫子浅凹，尾巴落后于身体；笑点是努力憋气的鼓脸。其辨识重点是“肩颊接触”，不是挥拳。后续若返修一级，也按此说明单独出图。
- **heavy_lv2｜二级**：有效撞击伤害累计+2。改为从角色背后斜上方看压缩瞬间：后脚离地、前脚撑住，软垫斜向深凹，裙摆和长发仍向来路甩；脸只露圆鼓侧颊。前景大块褶皱与背面剪影应明显区别一级；不能把身体画胖一圈表示升级。
- **heavy_lv3｜三级**：累计+3。低机位的接触特写，软垫和被挤扁的肩袖占画面大部，奶凶圆眼从垫边挤出来，鞋底与短粗回弹褶皱交代重量；身体不完整入镜。用近距离接触、强压缩和反向惯性区别前两级，不画锤子、护甲或击碎目标。

### 外包 / companion

- **companion_lv1｜外包一级**：主角+恰好1名伙伴。斜侧全身，主角脚掌撑地，用肩部接触把伙伴弹送出去；伙伴惊讶张手，裙尾顺着出发方向拉开。重点是“一次交接和一个小帮手”；保留历史母版供对比，不出现第二个伙伴。
- **companion_lv2｜二级**：主角+恰好2名伙伴。高处俯视的三角构图：主角居下，两名伙伴在左右前方不同待命状态，一名接触蓄势、一名踮脚等候，互不重叠。用三角分布和完整两个人形区别一级；不是同时发射多枚主球。
- **companion_lv3｜三级**：主角+恰好3名伙伴。横向“外包点名”小场面，主角侧身回头，三名伙伴分别举手、认真站直、慌忙整理围裙，四个清楚剪影；统一服装但表情不同。展示队伍人数，不复刻三级排队冲拳，也不暗示自动跟随或复制分身。

### 快速上弦 / cooldown

- **cooldown_lv1｜一级**：冷却2.2→1.95秒。侧面跪坐，双手拧回单个空托槽的弹簧机构，脸颊憋气，清楚看出“收回准备再用”；保留历史一级参考。只有一个空槽，不能画多弹药。
- **cooldown_lv2｜二级**：1.95→1.70秒。机位改为桌面斜俯视，主角一手压住底座、一手快速转回把手，发梢慢半拍绕过肩部；空托槽和曲柄形成清楚L形。动作、手的位置与一级有别，不靠多一根速度线交差。
- **cooldown_lv3｜三级**：1.70→1.45秒。手部与机构近景，手掌刚松开，单个空托槽已回到准备位置，主角圆眼从后方探看；一段弯曲回程线与收拢弹簧说明返回更利落。不要多个同形残影托槽，以免误读为双发。
- **cooldown_lv4｜四级**：1.45→1.20秒。主角坐在地面轻松转动短把手，单槽机构斜向占前景，反弹手柄将她的刘海吹起，表情从费劲变成得意。大幅改变全身剪影和动作节奏；仍是单槽、不是零冷却或无限连射。

### 逍遥游 / glide

- **glide_lv1｜一级**：自身阻尼×0.75、摩擦×0.70。低机位侧面短距离滑过平面，双臂张开找平衡，一只脚轻蹭地，裙边受摩擦卷起；短滑痕紧贴脚底。重点是初次“滑溜”，不画翅膀、冰鞋或空中飞行。
- **glide_lv2｜二级**：重复乘算上述系数。斜俯视，主角坐低重心侧身滑行，脚尖前伸，尾巴从后方弯过来，长而连续的弯痕穿过画面；发梢与身体有明显相位差。改变姿势而非照搬一级并加长线。
- **glide_lv3｜三级**：第三次乘算。较宽的顶视构图，主角沿一个舒展S弯侧滑，头回望来路，头发、尾巴与裙摆组成反向弧，地面留白很大。滑行路径和小人物剪影是焦点；不出现高速攻击爆花，不暗示额外冲量。

### 冲刺 / launch_power

- **launch_power_lv1｜冲刺！冲刺！一级**：主动发射冲量+15%。近地侧面，主角从压缩软垫起点刚被释放，前脚擦过地面，双手惊讶张开，软垫由凹到回弹；重心仍贴近地面。区别重击的“撞到东西”，本张是“从起点离开”。
- **launch_power_lv2｜二级**：累计+30%。从起点后方看她斜向远处冲出，前景软垫明显回弹，背影头发拖后，起点和人物间有清楚空隙；方向笔触短粗。不能画两名主角、火箭或喷气背包。
- **launch_power_lv3｜三级**：累计+45%。正面偏斜的强透视，角色向镜头贴地冲来，脸圆而惊讶、两颊被气流向后带，尾巴和起点压缩在远处；前景鞋与裙摆有惯性拉伸。靠前后透视与出发爆发区别二级，不靠换色或新增主动冲刺技能。

### 缩小危险范围 / shrink

- **shrink_lv1｜小小的也很可爱一级**：敌人脉冲/首领震波范围缩小15%，身体和碰撞体不变。俯视完整盔甲敌人，其危险红波边缘像过长裙边；主角从画面边缘探头，用两指捏起一小段外缘，荒诞地“收边”。敌人自身比例固定且仍显危险，不做缩小敌人的特写魔术。
- **shrink_lv2｜二级**：第二级继续缩小危险范围。近地斜侧，敌人仍同一身体比例，主角蹲在外侧将两折红波边缘向内收起，外面留出明显安全留白；画面焦点在折起的波边而非敌人脸。插画是范围收束隐喻，实际数值由文字表达，不画护盾、无敌或变小碰撞体。

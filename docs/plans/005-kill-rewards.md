# 击杀奖励与肉鸽发育雏形

用户要求：先Review并PR旧Demo，然后先列计划、一次性实现击杀门槛奖励及丰富发育选项。旧基线已在PR #2（38645c3，包含528e8e6）独立审查、修复并上传，后经外部合并至main的cc33ed5；新工作在 `codex/kill-reward-prototype`，不混入旧PR。

目标：从清波一次升级改为战斗中累计击杀领奖，奖励有实际收益、等级/上限、互补路线，并能无残留地暂停、继续和重开。保留五波/首领结构、全屏冲量发射、正常时间倍率、默认不跟随和实体障碍碰撞。

## 1. 奖励节奏

- 首次6击杀；之后每次门槛+2，最多16。门槛作为检查器参数可调。
- 击杀只认一次死亡；同帧爆炸/二连撞可跨多个门槛，累计排队，不能漏奖或重复发奖。
- 在统一整局推进点打开奖励，暂停整棵战斗树，取消瞄准；保留飞行中的球/危险弹位置与动量，不因领奖删除危险弹。
- 连续待领奖时逐次选，全部完成再恢复战斗。死亡/首领胜利优先，不在结算后弹奖励。
- 清波不再额外赠送升级，仍等待残敌和预警队列清空后进入下一波。五波结束进入首领；首领召唤小怪也计击杀，首领死亡直接胜利。
- HUD显示本局击杀、下一奖励进度、待领奖数和发射次数。

## 3. 分工和文件边界

- 构筑Agent：run_build.gd、upgrade_definition.gd、upgrades资源、roguelite_build.gd；提供15项池、兜底、等级派生、3/4候选与权重。不得写整局/发射/战斗脚本。
- 发射Agent：launch_controller.gd、player_ball.gd的物理参数入口、roguelite_launch_rewards.gd。双发兼容默认单发；begin/cancel不施冲量；增益从固定基础值重算，不能重复apply指数叠加。
- 战斗Agent：collision_combat.gd、enemy.gd、boss.gd、新assist_effects.gd、roguelite_reward_effects.gd。实现分级重击、有限二连撞、缩范围与无伤震退；不改整局/HUD/构筑资源。
- 主Agent：击杀进度/队列组件、run_director、run_hud场景/脚本、整局测试、教程/目录/STATUS与集成。

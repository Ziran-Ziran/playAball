# 第二轮：构筑重选与精准连击兑现

负责人：gameplay_assessment，根Agent集成/独立验收。日期2026-11-10。来源为用户完整体验提升要求与第一轮18局数据；不是已经通过的结果。第一轮流程设计复评仅5.7，伙伴不普遍变强、机动未改善、经济宽裕，因此继续小批补强，不把一次技术通过当发布验收。

## 目标与锁定规则

- 用真实金币获得有限构筑确定性：每局最多重选3次，价格6/10/14币，共30币；对比第一轮新局末余额23～41，足以形成与12币后段成长/6币治疗的机会成本，不加收入，不无限刷新。
- 任意合法升级来源可重选，来源和待领取奖励数量不变，正常支付成长不能再扣原成长价。无不同合法候选时禁用且不付费；至少保留首奖外包保证，已满级/缺前置/满血治疗均不入池。每次重选至少出现一个不同ID。
- 同一主球发射链实际直接命中3名不同普通敌人，最多一次返还已有发射冷却0.5秒。不计回声、爆炸、余势、敌人投射物或伙伴，不跨链累计。全弹药时不产生额外储存/未来返还。使用正式refund_cooldown，不改冲量/物理频率。
- 卡片入场未结束、旧面板、旧revision、重复鼠标事件、死亡/重开均不得扣费或兑奖。精准连击通过只读事件反馈，不在Combat里画图。

## 所有权与数据流

独占run_build.gd共享资格函数、run_director.gd事务与回能校验、run_hud.gd控件/入场、collision_combat.gd实际直接命中计数；launch_controller.gd仅必要时修改已有refund接口。保留根Agent已有deferred布局生命周期守卫。新增tests/roguelite_build_economy.gd、tests/roguelite_build_economy_gui.gd及教程060。其他角色/表现/Live2D/平台文件不改。

Build.eligible_upgrades是唯一候选资格源，原candidates复用它。重选从当前合法池扣除旧ID得到可变化项，先正常生成一次候选，再保证包含一张池外于旧offer的合法卡；不以无限抽样凑变化。首奖保底外包仍保留。Director在支付前校验状态/报价/入场ready/替代池，支付后同步递增revision并重建面板，重复点击被旧报价或新入场锁挡住。

HUD独立紧凑行显示余额、费用、余次和Button，不删卡片规则。面板测量在三卡/四卡与1024×576、1280×720校验，若最小高度超出视口，使用显式卡片滚动区，不隐藏卡片文本。每卡tween完成检查卡对象、父容器与当前offer，不能让已移除卡的延后回调解锁新报价。

Combat只在实际主球直伤后登记唯一普通敌人ID；第三个不同目标时标记链已结算并发事件。Director复核state=BATTLE、局revision、主球当前chain、生命和有效对象，调用refund。全局combat reset清链，重新发射切新链不积攒旧数。附加伤害继续使用P1来源生命周期守卫。

## 三轮玩家反证（实现准入，不是试玩）

1. 新手：不理解重选和连击也应能照旧选卡/发射。反证是重选按钮吸走注意、增加屏幕密度。修订为可跳过紧凑次级操作，仅升级暂停期间显示，说明“换候选，奖励不增加”；回能不要求新输入。设计准入通过，真实阅读/点击仍需GUI与真人确认。
2. 熟练：玩家攒钱找第二伙伴/R/X，仍需承担随机结果并放弃治疗/整备。反证是可重选很多次刷到必胜组合，或同样一组白扣钱。修订为每局3次递增6/10/14，至少一ID变化，但不保证想要卡，合法池耗尽禁用；报价明确，机会成本总30币。设计准入通过，是否实际帮成型须自然局验证。
3. 极限：排列3敌打穿换0.5秒，可主动利用二次发射追击。反证是同敌弹墙重复/补刀计数、同帧重置跨局、满冷却溢出或双发刷新无限回能。修订为真实直伤/不同ID/同链一次，退款只减已有remaining，所有来源/局/链检查后才发只读兑现反馈。设计准入通过，是否有感需记录实际发射等待与兑现次数；不先预设提高评分。

# 球体美术、特效、卡片文字与瞄准决策静止

日期：2026-11-05。基线cfe31a2，当前分支`fix/map-blueprints-20261105`。用户已认可第一张样例的大肥鱼团子球、分级病毒和整体表现方向；GPT/Claude/千问形象须重新查证网络特征。用户明确要求记住全部任务、交子智能体执行并验收；新增截图需求为“瞄准时全屏静止，发射后恢复，给决策时间”。

## 范围与设计

1. **主角球**：蓝发、鲸鳍、白色女仆头饰、鲸尾的大肥鱼团子球，非普通蓝鲸。使用内置imagegen生成透明独立贴图，在实际58像素显示尺寸检查。
2. **同伴球**：GPT、Claude、千问各一款。先核查公开参考，保留实际可辨认的符号/吉祥物特征；不得把任意换色少女宣称网络通用形象。仍是圆球轮廓，保持原伙伴数、半径和接力。
3. **敌人球**：互联网病毒主题，低/中/高等级分别有不同轮廓和外壳细节，不能仅换颜色。按出生最大生命映射等级，受击后保留身份；准确剩余HP和原生命颜色仍明确显示。脆皮/重型/炮台角色仍通过短刺、装甲/喷口等可读线索区别；首领保留核心+四模块的真实碰撞与弱点。
4. **特效**：单体瞄准箭头、柔和尾流与释放缩回；球体轻微受撞压缩、启动/接力/死亡反馈只消费真实事件，不能伪造命中或扩大伤害。用户后来否定五个重复小V，明确要求网上成熟素材，现采用Kenney CC0圆角单体箭头、导航对照及粒子尾流，新外观待审美评审。
5. **卡片文字**：克制、可读、非塑料的真实中文艺术字体，细描边与短阴影；长标题、三卡/四卡与小窗口不溢出。正文和数值保持动态可读。精修生硬/旧盔甲设定文案，不改Buff真实效果。
6. **决策静止**：真正进入瞄准后冻结战场物理、机关、敌人攻击预警、弹体、刷怪与战斗计时、恢复中的冷却；输入、UI及箭头仍可工作。释放有效发射或右键取消后恢复原动量；冷却未好时保持原按住等待，准备好才冻结，避免自锁。Esc/菜单/失焦/胜负/重开不能夺取其他暂停所有权或卡住。默认启用，参数可编辑。

## 目标与验收

优先让玩家通过选牌、站位、接力和经济投资获得可理解、可重复兑现的高反馈。单纯提高伤害或堆资产数量不作为体验提升的证据。保持 RigidBody2D 冲量、120Hz、Compatibility 与固定 Godot 4.7.1。

- 16 项成长逐项评分；组合关系完整可追溯；整局按阶段评估。运营深度与收益兑现合计权重至少 50%，明确区分推演、自动物理测量与人工试玩。
- 每项玩法改动有问题证据、玩家视角反证、边界和回归；新手、熟练构筑、极限/失败路径至少三轮复评。
- 对每份资产建立台账，标明正式引用/历史、实看/元数据、角色身份、尺寸导入、来源和处理结果。保留 DS 鲸鱼娘人物；现有 Live2D 文件不修改。
- Windows 与安卓分别验证输入、暂停、重开、布局与发布包。没有真机结果不宣称安卓手感、性能或兼容性已验收。
- 正式成品应有引擎版本、源指纹、包校验、构建日志和已知限制。签名/渠道发行条件与本地 release 构建分开记录。

## P1 锁定设计与实现责任

评分见 [玩法诊断](../reviews/2026-11-10-gameplay-assessment.md)，包含16项、120对组合与三轮玩家视角反证。取“机制兑现”方案：保守调参已有坏例证据；大规模扩写会稀释局内规则和验证资源。保留基础冲量1050、反向抵消0、冷却2.2与传能0.85。

gameplay_assessment 独占 `collision_combat.gd`、`run_build.gd`、`run_director.gd`、三项升级资源和 `upgrade_card_copy.json`；新增 `tests/roguelite_strategy_payoff.gd` 与教程056。根 Agent 负责测试接入及用途目录，A后续接管卡片收益短句，不交叉编辑。

1. 接力专精只奖励真实第2/3代伙伴直接命中，分别加1/2伤害；第1代不加，链仍最多3代，不改传能或冲量。
2. 爆破仍每链一次、固定1伤；按触发伙伴代数半径80/96/112，让站位和接力投入体现在可预测覆盖上。不递归。
3. 保龄球直接撞杀普通敌人时，从真实撞击点沿入射方向产生120距离、前方点积至少0.5的余势；最近最多两个存活普通敌人各1伤，墙/挡板阻断，不伤Boss、不递归、不触发回声/爆破/下一代。未击杀仍沿用原活体投射物。只有实际扣血才发只读成功事件。
4. 波4保留原免费补给，同时增加可跳过的12币成长/6币疗伤，各限购一次。付费成长后返回补给，不能消费击杀奖励；余额不足、满血、重复及旧revision拒绝。
5. 默认正式每局随机种子；显式正值保留固定复现。不能让新随机性使既有测试不可复现。

先运行新增回归确认红灯，再实现并确认绿灯；覆盖代数、重复、目标上限、墙阻断、Boss、同帧死亡重置、付费/免费共存和种子。后续运行同策略/种子的自然流程对照，保留死亡/截尾，不通过赠送HP、钱币或清场制造胜利。实际规则、收益文案和只读表现必须一致。

## 2. A：音效优先整改

### 现状与原因

`scripts/impact_feedback.gd` 目前生成一个约0.1秒的衰减正弦音，撞击和吃饭主要靠同一音源调音高。并发上限只控制数量，不能解决单调、密集叠加疲劳和事件缺乏辨识度。用户实际听感已判定不合格；WASAPI设备异常是另一问题，不能用它解释或否定用户反馈。

### 文件与边界

- 修改 `scripts/impact_feedback.gd`：保留旧场景接口和视觉职责，将新 Demo 的声音路由到独立播放器，避免误改旧侧视物理/接触规则。
- 创建 `scripts/roguelite/audio_director.gd`、`audio_palette.gd` 与 `resources/roguelite/audio/default_palette.tres`：分别管理事件播放预算、可编辑事件音组和资源配置。
- 修改 `scenes/roguelite/run.tscn`、`scripts/roguelite/run_arena.gd`、`run_director.gd`、`run_hud.gd` 的必要信号接合；机制发事件，播放器不反向计算伤害。
- 创建 `tests/roguelite_audio.gd`；更新教程、用途、目录和verify/CI。

### 实施步骤

- [ ] 先保存一段当前30秒密集碰撞试听参考，记录当前音量，便于同音量比较。
- [ ] 将事件分成：轻碰、重撞、敌人击杀、玩家受伤、白饭拾取、升级确认、阶段完成、胜利/失败；空拖/取消保持无碰撞音。
- [ ] 每个高频碰撞组制作至少3个有音色差异的短样本，避免只是单个正弦变调；用短促低频主体、弱噪声瞬态和柔和尾音区分轻重，降低尖锐高频。可先自主合成/录制本地样本，不自行下载或拆包角色素材。
- [ ] 音组避免连续重复同一样本，音高变化小幅且有界。重击/击杀有层次，玩家受伤与危险提示优先，普通墙面轻碰低优先级。
- [ ] 高频同类事件限频、密集连锁做音量压低/合并；为关键受伤/确认保留声部预算，防止8个普通碰撞吞掉提示。
- [ ] 独立SFX/UI音量与静音，暂停/新局正确清理旧音源；限制峰值并留余量。先用默认中低音量，不靠“调小总音量”掩盖难听的音色。
- [ ] 自动检查事件选组、重复回避、预算/优先级、静音、暂停/重置和旧接触去重；headless只验证调度，不能验收声音。
- [ ] 真机试听静场单撞、10秒密集连锁、受伤和奖励确认；耳机/扬声器至少实际可用的一种，记录设备和是否有WASAPI错误。请用户确认“不刺耳、可区分、不过度重复”后再把音效状态改为通过。

## 4. C：成长与难度的大趋势，阶段之间休息

### 方案比较与推荐

推荐在现有五波上先组成3个阶段，不新建地图系统：阶段1为波1～2，阶段2为波3～4，阶段3为波5＋首领。阶段1后商店、阶段2后事件，阶段内保留累计击杀三/四选一。这样较快验证“战斗—选择—休息—更难战斗”，复用现有敌人/首领与奖励池。

备选是每波都进休息区：更容易接入，但五次打断可能割裂物理连锁。另一方案是直接做完整路线地图、多房间和大量随机事件：扩张过大，现阶段不采用。3阶段和间隔内容是建议起点，正式替换当前流程前向用户简述数量、经济与进入条件；不默默把建议改成既定核心规则。

### 状态与不变量

引入明确的 `BATTLE / REWARD / STAGE_CLEAR / SHOP / EVENT / TRANSITION / VICTORY / DEFEAT` 状态；普通Esc暂停仍是独立的暂停原因，不能让关闭暂停菜单跳过商店/事件或奖励。

- 初始等级、货币、同伴数量保持基础配置；每局增长从零开始，无局外数值继承。
- 普通击杀奖励仍按6/8/10…16计算，跨波、跨阶段保留进度；不因为休息区重复发奖。
- 当前阶段停止刷怪后，等残敌与生成预警清完，先处理待领奖，再进入休息区。主球死亡优先失败，首领死亡优先胜利。
- **战斗中领奖**继续保留危险弹/动量；**阶段结束休息**显式清理上一阶段危险弹、临时攻击资格、旧回声、白饭与预警，杜绝购买时受伤或下一阶段旧事件误触发。两条规则要分别测试。
- 休息期间停止物理、刷怪、冷却和能力计时；玩家当前血量/升级/货币保留。购买治疗只在确认交易时加血，不能通过开关界面刷恢复。
- 不为界面移动或逐帧改刚体位置。继续战斗前取消旧输入，给3秒可读准备提示及安全生成预警；若需重置刚体，必须使用已有物理状态接口并说明原因。

### 第一版商店/事件建议（历史草案，实际实现见教程013）

货币先采用每个有效普通敌人死亡+1，复用死亡唯一性，不与伤害次数挂钩；所有交易原子化校验余额、库存和报价版本。初始0，重开清零，余额不足按钮禁用但仍显示原因。

商店先只有两种限购一次的商品：4币恢复2血（满血禁买），8币购买一次从当前合法奖励池生成的三/四选一。购买的奖励不消费击杀进度/待领奖队列，使用独立来源标记；不能回退重复购买、刷满级或绕过前置条件。允许不购买直接继续，不做刷新、利息或永久商店养成。

事件先做一个完整可复现的“补给摊”：选择恢复2血、获得6币或跳过；每次进入只结算一次，满血时治疗选项禁用。先验证选择与休息确实有价值，再扩展风险/收益事件；不先堆大量只有不同文案的事件。

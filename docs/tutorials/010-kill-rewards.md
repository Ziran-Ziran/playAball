# 教程010：击杀领奖与十五项发育雏形

本轮在已独立Review且CI通过的 [PR #2](https://github.com/Ziran-Ziran/playAball/pull/2) 基线上开发，当前本地分支 `codex/kill-reward-prototype`。完整入口仍是 `scenes/roguelite/run.tscn`，打开F6；窗口标题含“击杀奖励 Demo”。F5旧实验、arena三靶场和零重力/正常速度规则保持。

## 一、击杀如何变成奖励

以前清一波升级一次；现在死亡信号进入 `run_director.register_kill()`，由 `kill_rewards.gd` 去重计数。首次6击杀，之后门槛8、10、12、14、16，并保持16。计数保留余数，一次爆破跨过多个门槛会排队，不丢失奖励。HUD显示发射次数、击杀和下一奖励进度。

到门槛不在物理接触回调里直接暂停，而是在整局 `advance()` 统一打开卡片，避免一轮爆破的后续死亡信号被漏掉。球、敌人和危险弹保留位置/速度并随树暂停。全部选完回到当前战斗；清波只进入下一波，不重复赠奖。五波清完仍进首领；首领召唤小怪计击杀，首领死亡直接结算。

每轮卡片带 offer_id：旧按钮的延后点击即使ID仍在下一轮候选里，也不能替玩家消耗下一次奖励。死亡/胜利优先于待领奖；重开清空死亡去重、击杀余数、候选、队列和构筑。

## 二、卡片与构筑

普通池15项，完整效果/等级表见 [计划005](../plans/005-kill-rewards.md)。`upgrade_definition.gd` 增加 category/weight，`.tres`记录标题、说明、分类、权重、上限。卡片显示当前级→下一等级，描述自动换行，三张或四张都可读。

候选规则：不重复ID、满级不出、满血不出回血、只有已拥有至少两颗小弟才出接力；首次奖励保证新同伴。优先提供不同类别，再按权重选择；已有类别投资最多增加30%权重，允许继续成型也能混搭。候选不足按实际数量展示，不用重复卡填格。普通池耗尽才提供独立强身兜底，增加本局生命上限1并恢复1。

五条可混搭路线：机动（强力发射/滑行）、火力（重击/二连撞/保龄球）、伙伴（数量/跟随/接力/爆破）、生存（回血/威慑/震退）、节奏（冷却/双发/四选一）。这是一版可验证的发育池，没有宣称最终平衡。

## 三、收益如何兑现

- 强力发射只改主动冲量；滑行改主球自身线性阻尼和独立材质摩擦。`apply_launch_stats()`从固定基础值重算，重复应用不会指数叠加，也不改逐帧速度/位置。
- 双发最多储存两次，每次松手分别消耗、分别编号，缺格按冷却逐格恢复。升级仅授予新增槽，重复同步构筑不能免费装弹；白饭返还只推进一次恢复。
- 冷却从2.2每级减0.25，四级最低1.2；升级保留当前恢复百分比，不重新从满冷却开始。取消/空拖不花次数，按住跨恢复仍可接上。
- 重击每级主球有效伤害+1，最多3级；低速仍无伤。二连撞在有效主球/小弟命中后0.12战斗秒追加1伤害，每来源/目标/链一次；不再次触发二连撞、白饭、爆破或保龄球。反馈放到目标当前世界位置；失效目标/旧局队列不生效。
- 威慑每级将普通脉冲和首领震波半径缩小15%，最多30%；不缩实体形状，也不改变首领真实接触伤害。
- 护身震退每4战斗秒对150内存活敌人给一次最多250×质量的向外冲量。没有直接伤害，不调用战斗解析、不改变链路归属；蓝色扩圈只解释这次震退，不冒充碰撞粒子。
- 跟随、接力、爆破和保龄球沿用既有去重/代数/目标预算，详见教程003/005。初始小弟仍不跟随，所有状态都碰实体障碍。

## 四、检查器与扩展

RunDirector新增 Reward First=6、Reward Increment=2、Reward Cap=16，改变后重开。`KillRewards.next_target()`会把无效零/负数钳到安全范围，避免无限免费领奖。

升级资源可调文字、max_level、category、weight；实际数值公式由DemoBuild派生API计算，调整上限要同步公式和测试。机动参数由DemoPlayer应用，双发由DemoLaunch管理，范围由enemy/boss.apply_attack_scale重算，震退由运行时AssistEffects的PAUSABLE组件管理。运行时组件用Remote检查器临时调参，持久值改脚本默认或今后保存为场景/资源。

新增奖励先写真实收益测试，再加资源和构筑派生，最后接到单一负责模块。不能只加卡片说明却不兑现，也不能每次应用把既有次数/生命重新填满。

## 五、验证与试玩

新增四套：kill_rewards（门槛/溢出/去重）、kill_run（真实死亡/排队/暂停/胜负/旧卡/重开）、launch_rewards（双发与物理参数）、reward_effects（延后伤害/范围/无伤震退）。构筑测试扩充为十五项池与资格/权重/上限。整套接入verify与CI，旧Run测试按新规则检查清波不再免费升级。

手动：F6开球击杀 → 看顶栏奖励进度 → 达标暂停，读类别/等级/说明选一张 → 继续同一波。重点试双发连射、四选一卡片是否完整可读、二连撞是否有两次反馈、震退是否只弹开不自动杀怪；重开后这些都应消失。长时间难度、抽卡偏好和构筑强弱仍须真实玩家反馈，headless通过不代表平衡完成。

## 与阶段休息衔接

当前本地版本在波2/4清场后加入商店/补给；基础击杀门槛和奖励队列不变，付费/事件成长不消耗击杀进度。区别见[阶段休息013](013-stage-rest.md)。生命显示见[011](011-health-panel.md)，音效与试听见[012](012-event-audio.md)。

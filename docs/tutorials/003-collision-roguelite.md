# 教程 003：俯视开球与同伴接力（P0～P2）

本文只介绍 `arena.tscn` 三靶场的P0～P2规则，该入口没有波次、升级、敌人攻击或胜负流程。完整肥鱼战斗已在独立 `run.tscn` 实现，见 [教程007](007-run-loop.md)；当前进展和人工未测项以 STATUS 为准。

## 1. 两个入口

Godot 4.7.1 stable 标准版导入根目录 `project.godot`。F5 仍运行旧侧视实验室，重力与停稳发射规则不变。打开 `scenes/roguelite/arena.tscn` 后 F6 运行新俯视场。

最短操作：游戏窗口全屏空白处左键按住，向下拖约 100～160 像素后松手，主球会向上撞初始同伴与上方靶。等待外圈充满（2.2 秒），运动中也能再发射。右键取消，Esc 暂停；暂停菜单可重置。小于 8 像素不会发射。顶栏可切换 1/2/4 同伴、动量 B、静音、关震动。

## 2. 场景与分工

- `arena.tscn`：TopBoundary/BottomBoundary/LeftWall/RightWall 四边围墙，Corners 四个斜切角，LeftRamp/RightRamp 平面挡板，PlayerBall、Targets 三靶、Camera2D、HUD。
- `arena.gd`：装配信号、全屏手势与按钮输入隔离、暂停和单球越界回收。发射与战斗逻辑放在各控制器。
- `combat_body.gd`：所有新战斗刚体的共同基类；零环境重力、接触报告、1500 限速、物理接口复位。旧 `ball.gd` 不继承它。
- `player_ball.gd` / `launch_controller.gd`：一次发射冲量 / 能量与输入状态。
- `companion_ball.gd` / `companion_manager.gd`：默认待命/出击、可选跟随升级 / 数量与初始摆球。
- `collision_combat.gd` / `destructible.gd`：统一伤害与接力解析 / 固定靶生命和一次死亡。
- `impact_feedback.gd`：共用亮环、粒子、合成音和震动。新场景覆盖 Particle Gravity 为零，旧场景保留原默认向下粒子。

## 3. 输入如何变成冲量

按下位置成为固定锚点，`anchor - pointer` 是发射向量，箭头跟着主球画。松手成功才花能量，最长拖拽 160；8～160 像素映射为最大冲量的 45%～100%。调用 `apply_central_impulse()` 一次，不修改逐帧位置。

默认 A 保留旧动量。B 开关令 `cancel_opposing_momentum = 0.6`：先计算 `min(0, velocity.dot(direction))`，只用一次反冲量抵消其 60%，再施加新冲量；同向与垂直速度仍保留。公式按向量投影计算，上下左右与斜向一致。选哪个版本要以玩家方向判断为准。

用户在试玩后确认取消拉动慢动作。拉动期间始终正常速度，按下/移动/取消不修改刚体速度；只有松手成功才施加冲量。运动仍受自然碰撞、阻尼等物理作用。松手后的冲量保留原有惯性，所以同向发射可能加速，这是主动发射的结果。

手势直接使用事件屏幕坐标，不随镜头震动改变；窗口全屏空白均可开始，真实 HUD 按钮独占点击。在按钮上松手取消。冷却中按下进入 input_held 等待，冷却完成后继续原锚点拖动即可；提前松手、右键、失焦或暂停会清除等待，不能等到就绪后幽灵发射。HUD 向上取整显示剩余冷却，只有确实可发射时显示“就绪”。

## 4. 接触如何变成伤害和接力

基类在 `_integrate_forces` 读取接触法线，以前一物理帧的入射速度估计碰撞前接近分量，发出延后信号，避免物理查询锁内改节点。它是玩法用的速度估计，不是精确能量测量。

解析器按 180/450/850 分为 1/2/3 伤害；低于 180 无伤。配对键把两个实例编号排序，同一对无论参数顺序都共用 0.18 秒冷却。静止不伤害，靶只派发一次 broken。记录 chain、source、target、generation、damage，最多 256 条，方便检查一次发射的收益。

待命与归队同伴没有实体球层，专用 Sensor 检测高速主球或出击同伴。有效交接给同伴一次冲量和来源编号，最多 3 代；已经出击的球不会重复交接。出击球之间的弹性碰撞由引擎计算，不再额外模拟传能。

碰撞层：1 为围墙/斜切角，2 为主球，4 为出击同伴，8 为目标，16 为内部挡板。主球 mask=29，出击同伴 mask=31；待命/归队 mask=25（1+8+16），始终与围墙、固定目标、内部挡板实体碰撞。对球仍用传感器接力。新层未修改工程原有层名称或旧场景。

## 5. 初始不跟随，跟随属于升级

初始 `follow_enabled=false`，主球走远也不会带着小弟走。出击最多 3 秒，或低于 180 速度持续 0.3 秒后结束攻击；`end_attack()` 清除攻击编号并回待命，保留惯性由阻尼自然减速。初始摆球位置不是持续跟随目标。

完整run取得跟随升级后，由构筑调用 `companion_manager.set_follow_enabled(true)`。本文的arena三靶场没有升级界面，默认不开启。开启后才用 `difference * 9 - velocity * 5` 的 PD 引导，力最多 420、速度最多 400、目标半径 110。遇障碍会被挡住，不穿墙或瞬移；本阶段没有复杂寻路。重置三靶场会关闭跟随。

正常运动只用力与冲量。越界时请求 `reset_body()`，由下一次 `_integrate_forces` 写 transform、清速度和攻击编号，只回收这一颗。不要在 `_process` 中连续设置刚体 position。新实例可以在加入场景前设置初始位置；这与运行中硬移位置不同。

## 6. 检查器调参和扩展

| 位置 | 参数 | 观察重点 |
| --- | --- | --- |
| player_ball 根节点 | Max Impulse=1050、Max Drag=160 | 满力是否可读；运动中再发射方向是否符合预期 |
| player_ball / companion_ball 根节点 | Gravity Scale=0、Linear Damp=0.12、材质 Bounce=0.85 | 零重力、冷却间仍在运动、借墙反弹 |
| LaunchController | Cooldown=2.2 | 不连发、按住跨冷却可接上、全程正常速度 |
| CompanionBall | Active Duration=3、Return Force=420、Return Speed=400、Follow Distance=110 | 散射覆盖与归队速度 |
| CollisionCombat | 三档速度阈值、Pair Cooldown、Max Generation=3 | 低速不刷伤、接力有上限 |
| Targets 下各目标 | Hit Points=3、位置、Shape | 同步修改外观与碰撞形状 |
| ImpactFeedback | Sound Enabled、Shake Enabled、Particle Gravity | 关闭表现不改变战斗 |

每次只调一组数值，重置后比较。新增敌人/危险刚体应继承 DemoBody，场景也明确 Gravity Scale=0，并补“无外力不漂移”的测试。肥鱼的白饭吸力以后以有范围、有上限的平面力实现，不能改工程默认重力；另外两个主题保留扩展。

## 7. 验证与常见错误

用实际引擎路径执行 `./tools/verify.ps1 -GodotExe <本机路径>`：版本、导入、目录、俯视 smoke、输入反馈回归、旧 smoke。新 smoke 不覆盖重力配置，检查八向发射/反向动量、四边反弹、冷却/取消/全程正常速度、碰撞去重/死亡、三代接力、四颗上限、四向归队、静止无抗重力漂移、单体回收、一次发射经两颗同伴击中两个不同靶。三靶散射夹具固定几何路线，不承诺随机开球次次两杀。

常见错误：只把主球重力归零却漏同伴；测试先归零重力掩盖场景错误；保留侧视抗重力导致同伴向上漂；把 B 写成只抵消 X；为避免归队受阻而关闭挡板碰撞导致穿墙；暂停后取消瞄准误解除暂停；把 headless 结果写成“手感已通过”。

人工门槛：两人各先不听口头解释试 30 秒，再记录 10 次发射是否至少 8 次方向符合意图；比较 1/2/4 颗同伴和 A/B。观察同伴是否容易撞出、能否借同伴击中两靶、默认是否不跟随、出击结束是否自然停留、是否被挡板和箱体阻挡。另检查失焦/暂停/右键、扬声器音质与退出日志。自动检查和 Agent 窗口操作不能代替这些玩家记录。

## 8. 玩家反馈修复的回归

`tests/roguelite_input_feedback.gd` 把鼠标事件送入真实 Viewport，而不只直接调用控制器：全屏四处、镜头偏移、连续十次发射、冷却按住跨就绪、提前松手、按钮独占、按下与取消不施加冲量。另用真实撞墙检查反馈点在墙面上，以及重置丢弃旧物理帧的延后反馈、移除现有粒子和音源。

碰撞点 `get_contact_local_position()` 名称容易误读，返回值已经是世界坐标；再乘刚体 transform 会让粒子和音源偏离接触点。依据见 [Godot 官方接触点说明](https://docs.godotengine.org/en/stable/classes/class_physicsdirectbodystate2d.html#class-physicsdirectbodystate2d-method-get-contact-local-position)。主球撞靶只由 combat.hit 播放一次反馈，墙碰走 impacted；回能与发射不再伪装成碰撞。复位递增事件版本号，延后派发时检查版本和发射编号，避免上一状态的事件混入下一状态。

小弟碰撞回归用独立内部墙检查真实反弹，覆盖默认待命、出击和升级归队；另检查固定目标碰撞层。引导测试的目标点和路径放在空地，不能再靠穿透实体靶通过。跟随升级的构筑/卡片仍属于 P3，本阶段只保留关闭的开关供之后接入。

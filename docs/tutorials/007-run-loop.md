# 教程 007：从三靶场到五波、升级和首领

P3 新入口为 `scenes/roguelite/run.tscn`，编辑器打开后 F6。旧三靶场 `arena.tscn` 保留；F5 仍是原侧视实验。不要为了试玩新场景修改项目默认重力或默认入口。

## 文件与节点

新场景继承三靶场的墙、挡板、主球、输入和暂停菜单。`run_arena.gd` 继承 `arena.gd`，移除固定三靶，隐藏同伴数量/动量调试按钮，加入 `RunDirector`、`Enemies`、`Hazards`、`RunHUD`。重开由 director 统一处理，避免只重置球却留下上一局敌人。

`run_director.gd` 只组织局状态、预警刷怪、波次和升级应用；敌人攻击由 [教程004](004-enemies.md)，构筑与碰撞收益由 [教程005](005-build.md)，首领由 [教程006](006-boss.md) 解释。`run_hud.gd/.tscn` 只绘制卡片/结算并发出选择或重开信号。

## 输入到整局结果

1. 主球满血5、1颗不跟随小弟开局。沿用全屏空白拖动，松手冲量发射，冷却2.2秒；全程正常速度。
2. 入口先画0.8秒空心预警，再创建敌人。创建前再次检查与主球至少200像素距离；玩家已走近时换安全入口并重新预警，不贴脸生成。
3. 每波前30秒刷怪，同屏最多24；之后停止刷新，等待残敌清完进入下一波；升级由累计击杀独立触发。没有倒计时清空残敌或自动判胜。
4. 升级状态暂停场景树、取消拉动并阻止发射。默认三张卡，运筹升级后四张；首次奖励保证新同伴，点选后应用真实参数，继续当前战斗。Esc不能绕过升级界面。
5. 共五次清波，之后单独出首领；清波不额外赠送奖励。首领最多召唤6名小怪；慢危险弹容器最多12。
6. 生命归零或首领死亡只结算一次，停止战斗与刷怪；R或结算按钮重开。战斗中重开通过Esc菜单。

`State` 区分 BATTLE、UPGRADE、PAUSED、VICTORY、DEFEAT。Director 自身始终处理UI，但只在 BATTLE 累计战斗delta；敌人、生命无敌计时和危险弹使用可暂停模式。取消瞄准不会解除升级或结算暂停。

## 升级如何应用

`build.choose(id)` 先验证选择，再由 `apply_build()` 更新冷却和跟随开关。增加小弟用 `add_member()`，不删除并重摆已有小弟；新增位置先查询障碍，避免放进实体内。满血不出现恢复，恢复只加2格并发出生命更新信号。重击、接力、爆破、保龄球由 combat 的 build 引用读取。

重开清空 Enemies/Hazards、预警队列、卡片、构筑、碰撞标记和表现节点，恢复5血、2.2秒冷却、1颗不跟随小弟。先从树中移除旧物体再延后释放，旧危险回调不能伤害新局。

## 检查器调参与复现

在 Run 场景选 RunDirector：Spawn Duration 默认30秒、Spawn Warning=0.8、Spawn Interval=3.4、Enemy Limit=24、Run Seed=31030。初版波次后期逐渐缩短刷怪间隔。一次只调一项；不把缩短调试波次测出的时长当正式局时长。

Debug Start Wave 默认1，可改6直接练首领；Debug Upgrades 可填升级ID。三个固定构筑：`companion`重复三次；`heavy,bowling`；`relay,explosion,follow`。重置会按检查器调试配置重建，普通默认配置始终没有升级。相同种子仅复现候选/刷怪抽样，不保证刚体轨迹一致。

`tests/roguelite_run.gd` 检查预警、清残敌、三选一/暂停优先级、五次清波到首领、死亡/胜利、固定构筑的运行参数以及连续10次重开。测试通过直接清敌和指定首领伤害来复现状态，**不代表玩家实际通关或4～6分钟节奏通过**。敌人、升级与首领还有各自独立测试，一并接入 verify.ps1 和 CI。

## 人工试玩与限制

F6 → 向敌人/小弟开球 → 观察空心预警与实心危险 → 击杀达标选奖励 → 比较打法 → 尝试首领或失败后重开。观察生命下降是否可理解，卡片是否可读，跟随后能否再次组织开球，以及后期敌人/危险弹是否遮挡主球。

当前几何肥鱼/小鱼与合成音，白饭吸引/饱饭强化已经接入，见教程008/009。音量滑条、静音与震动均只影响表现，音源并发最多8。跟随只有物理引导，没有绕障碍寻路，不能穿墙。真实两台设备性能、三构筑各完整一局、首领45～75秒与整局4～6分钟仍需玩家记录。超过60秒残敌目前不会自动削弱或消失，玩家仍需清完。

新版击杀领奖、十五项池和四选一详见 [教程010](010-kill-rewards.md)。领奖保留危险弹并暂停，选完继续当前波次；清波与领奖互相独立。

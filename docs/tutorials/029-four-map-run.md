# 四地图与完整整局接线

2026-11-05按本轮四图修正，当前节点、尺寸、调参与新验收见[教程041](041-map-blueprint-correction.md)。旧版布局与验证计数不代表本轮验收。

正式F5主菜单→开始进入地图一。波1–2翻转挡板；波3–4十字与局部尖刺；波5旋转弧与传送；波6内外旋转首领场。波2后商店、波4后补给及倒计时保留。主动技能和随机地图没有加入。

## 从文件到运行

`resources/roguelite/maps/*.tres`保存名称、边界、主球/首领出生点、敌人入口及安全区域。`scenes/roguelite/maps/*.tscn`是真实可编辑布局，引用[机关教程028](028-map-mechanisms-portals.md)的独立组件。`map_layout.gd`给实际障碍的视觉子节点复用既有暗绿墙条位图，碰撞和图案一起随机关运动。弧段纹理当前重复明显，是后续表现优化项，不当作最终美术验收。

`RunDirector.start_wave`→`MapController.select_wave`选择地图；相同地图的两波连续运行。真正换图时先停机关、取消门请求、移除旧地图，再实例化新场地并绑定主球、生命和传送边界，按实际碰撞空间找主球/伙伴安全点。位置修复通过DemoBody.reset_body物理接口，不写刚体位置模拟运动。构筑、生命、金币、发射冷却和累计奖励不重置。旧地图的弹体、白饭、延后补刀及接触缓存清理，已有伙伴保留，攻击资格结束后安全落位。

主球从地图出生点开始；首领使用独立右上出生点，包含Core半径43与四个偏移60、半径17模块，最大碰撞外伸77。不能只按43检查首领是否塞得下。新地图保留继承围场的外墙/角部，旧LeftRamp/RightRamp禁用碰撞和隐藏；皮肤跳过它们，不留下不可碰的旧墙影。

## 暂停、成长与休息

战斗→暂停、成长、商店、补给、胜负均显式`maps.set_active(false)`；它取消尚未执行的传送，停止移动/旋转和尖刺，冻结翻转刚体但保存其动量。回战斗恢复。倒计时仍由原始PROCESS_ALWAYS的RunDirector推进，地图保持停用，直到下一波启用。重开强制重建第一图，旧地图节点、尖刺组、门锁及未完成增员请求被清理，恢复零伙伴。菜单释放整局，不留下活动地图。

首领撞击layer1/16的真实PhysicsBody2D墙/挡板开弱点；新翻转挡板是RigidBody2D，因此扩展旧的StaticBody2D判断。未把球、敌人或无实体图案当墙，也没有改变首领伤害、生命或攻击时序。

## 安全生成与恢复

敌人入口优先选离玩家至少200的当前地图入口；预警结束时再次查询实际墙、机关、尖刺和实体。入口全部不可用时等待下次刷怪，不贴脸或硬塞墙。普通敌人半径与重型半径分别检查；分裂保留原有80距离、共享预算和有限重预警，排除已逻辑死亡且即将禁碰的父体，防止共享地图查询把死亡父体误作永久障碍。

伙伴增员与出界恢复读取当前地图边界/安全查询，跟随目标也从边界夹取。主球出界恢复读取同一地图出生点；白饭仍用既有候选点，但增加当前地图碰撞/尖刺复核，不能因为只检测实体墙而生在红刺上。

## 手动修改方法

编辑器打开某张地图场景，选中组件调整position、rotation及导出的轨迹/角度/速度；地图数据资源改出生点和入口。不要仅修改截图或背景。地图三和首领环的每段CollisionPolygon2D与对应Visual多边形同时改；移动尖刺挂在实际Body下，不能挂在静止根节点。首领内圈四处短刺使用26×19碰撞资源，不能只改length绘制而保留180宽接触区。

地图三两弧半径160、厚18，缺口初始位于左上/右下，随同一Body缓慢旋转；水平尖刺板沿世界X轴镜像移动。首领内圈半径60且封闭、外圈180，外圈四个30度入口；主球左下、首领右上出生，绿门上下互传、黄门左右互传。上下短翻板的全扫掠范围不碰外圈或外墙。修改后必须重跑真实空间通道检查，不能只量图上像素。

改地图顺序只改`MapController.MAPS`与选波映射，并同步测试和本教程。不要在暂停控件或表现脚本里改波次/经济。实验室仍是独立固定夹具，不自动换入正式四图；其原型默认边界与地图数据当前相同，正式运行的安全接口不会污染独立夹具的显式覆盖。

## 验证与限制

本轮新增图纸94项与导航50项通过；以下计数和中心出生/左右大缺口记录仅为旧版历史。当前验证以教程041及STATUS为准。

`roguelite_maps.gd`检查四图正式入口、波次对应、生命/金币/构筑保持、唯一活动地图、独立首领出生与重开，39项。`roguelite_map_flow.gd`从正式菜单验证成长→商店付费→补给→首领→胜负→重开→回菜单，还验正式暂停取消传送和真实首领撞刚体挡板，24项。它明确主动清场、推进到期及注入击杀事件，只是流程夹具，不是自然战斗通关。

`roguelite_map_navigation.gd`在实际碰撞空间，以8像素网格、主球半径23检查地图三与首领图0–88秒的12个旋转快照，38项；同时检查整个首领半径77的出生净空及完整Core/四模块加3像素余量穿过初始左右门。首版100度内圈缺口未满足模块余量，实际放宽为120度，六处短尖刺和首领攻击参数保留。原始结果在`.local/map_navigation_results.json`。这是离散快照覆盖，不声称穷尽所有时刻、所有拥挤状态。

新增测试加入`tools/verify.ps1`与CI本地配置，组件接线当时共33套行为检查（历史计数；本轮扩至38套，见教程033）；最终结果见STATUS及`.local/overnight`日志。真实Compatibility1280×720、1024×576四图截图也保存在该目录，截图由固定场景夹具产生。自然完整局的平衡与人类操作体验仍待后续代理评估及玩家判断；不能把这些状态断言写成人工通关。

常见错误：清波还没结完奖励就换图；休息只停计时却让机关继续运动；移动门出口不二次核验；地图切换重置金币或重新赠奖；伙伴保留旧地图坐标；无处生成时使用INF；旧测试固定坐标现在落在新墙中。最后一种应把夹具移到新图实际安全点，保持原验收断言，不删除安全查询让测试硬过。

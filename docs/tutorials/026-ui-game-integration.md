调试保留为独立F6入口：`gameplay_lab.tscn`为固定夹具；`tuning_run.tscn`为B线全局/实时调参完整一局；`arena.tscn`为旧靶场，`scenes/main.tscn`保留旧实验。正式game不实例化LiveTuning或TuningPanel，不加载个人调参预设。普通Windows导出从主菜单进入；显式`-LiveTuning`才导出调参版。

## A/B快照汇合

集成基于32e0e4f（B接口与实验室已在主线）。A原目录未提交的文档和UI复制到隔离工作区，B另一个目录尚未提交的实时调参/完整引擎调参也按文件复制；原目录不提交、不切分支、不重置。源文件SHA记录在忽略的`.local/source_snapshot.json`供核对。STATUS分别保留两线事实，file_purposes按A相对旧基线的增量叠加B清单，FILE_MAP重生成。

## 主菜单

`scripts/ui/main_menu.gd`使用`assets/ui/`中的独立角色、标题、背景和完整按钮。文字/图标按用户指定已在按钮贴图里；TextureButton保留动作和键盘焦点。alpha点击mask让透明边距穿透。开始切到正式game，设置调Master音量并写入`user://ui_settings.cfg`，退出关闭进程。图像用独立TextureRect，不能拦截按钮。

修改贴图可在ART目录替换对应文件；布局用main_menu.gd中的Rect2调整，1280×720逻辑画布随工程canvas_items缩放。角色已认可，窗口大小变化后要复核按钮的透明热区与标签可读性。设置面板当前为功能控件，尚无单独通过的设置面板美术。

## 战斗与选卡

game外壳隐藏旧HUD Controls和长操作提示，右上显示阶段/波次、金币和真实成长进度，并从HUD原图裁取金币、暂停、进度条；文字使用真实数据。左上`health_skin.gd`消费B的DemoHealthView.snapshot()，源状态仍由玩法推进。冷却继续留在球上，未重画冷却环。

`assets/ui/health_skin.png`保留已生成HUD原图，通过Atlas裁取十字、边框、红格和空格；不裁入示例4/5数字。`health_cell.gdshader`仅裁掉相邻格像素。上限不超过12时一格对应1生命；超过12时聚合为12格，最后不足部分按比例裁剪，准确hp/max数字始终显示。每2秒一轮，前0.65秒从左至右逐格提亮，只亮实际有血部分；暂停停止时钟。要调整力度，改health_skin中的peak倍率；改格数/上限时必须同时测空血、满血、部分格与数字。

`assets/ui/arena_skin.png`是已认可的四面薄墙全景原图，`arena_skin.gd`只抽取不含HUD的地面和墙条，再按原场地坐标贴到四墙、拐角和两块斜坡。Corners仅只读碰撞多边形生成视觉Polygon2D，旧Visual隐藏；碰撞形状、位置、层、冲量均不变。game._draw只保留原手势瞄准箭头。替换源图后需在脚本Rect2区域重新指定无字部分，禁止直接铺整张带示例数值的截图。

`assets/ui/panel_base.png`使用Atlas去除原图透明边距，32像素内容安全区用于暂停、奖励、商店/事件面板。控件是原玩法按钮，贴图只做背景；基础按钮不另造不存在的美术。大图源均随工程携带，运行不依赖本机生成目录。

run_hud中的Cards从VBox改为HBox，以已通过的空白v2卡框贴图为StyleBoxTexture。卡名、类别、等级与描述仍取真实奖励数据，不将动态数据烘焙。每张延迟0.1秒、0.42秒平滑上移24像素，入场锁定至落稳再启用，边缘流光为独立鼠标穿透层；使用暂停期间可运行的Tween。具体卡面插画仍未设计，本批不伪造图案。可修改卡框资源、卡宽、字体与内容边距，须复核四张和长中文。

本批已经使用现有菜单、血框、场地、卡框与通用面板素材；尚无具体卡面插画，按用户要求留空不补图。已有贴图不代表任意未制作卡面已获批准。

## 验证方法

固定Godot4.7.1 stable标准版：先`--headless --editor --import`，再运行`tests/ui_integration.gd`，再执行`tools/verify.ps1 -GodotExe <实际路径>`。新测试覆盖菜单按钮类型、正式场景无调参节点、隐藏调试控件、受伤/恢复与重开、生命格数跟随上限变化和空格填充、四卡数量/贴图。原27套回归继续覆盖B实验室/调参、旧完整run和旧实验。

主菜单→开始→空白拖动；Esc暂停→继续/重开/返回菜单；受伤、升级三/四卡、商店/事件、结算后重开仍需真实窗口验证。自动状态检查不等同真人通关或音质验收。结果、独立审查和限制记STATUS/最终Review记录。

暂停菜单保留玩家可用的静音、震动、击破分裂开关及独立音效/提示音量；只有开发控制与调试读数被隐藏。设置打开时禁用背后的开始/退出按钮，返回后恢复，防止穿透操作。

# 024：在试玩EXE里实时调手感

更新：用户随后要求所有引擎可控量，现已扩展为[完整调参台025](025-full-engine-tuning.md)。本篇9项保留为“常用手感”快捷模式；默认打开完整属性。F9/恢复和对照/保存同时覆盖高级属性，schema升级为2并兼容旧文件。

用户指出手感的物理量需要现场调，不能等打完一局再填长表。本功能让策划在同一局中改数值、立刻发射比较，把满意参数直接保存或复制回开发者。策略、成长和难度节奏仍适合逐局记录。

## 入口与操作

- 策划版入口：`scenes/roguelite/tuning_run.tscn`；编辑器打开F6，或导出时加`-LiveTuning`。
- 启动直接打开调参面板并暂停。拖动滑杆或改数字即应用，不需要点“应用”、重开或重新导出。
- `F1`或右上角按钮收起面板继续试；面板打开时Esc也会收起。正常游戏的Esc暂停仍保留。
- 默认勾选“调参时暂停战斗”。关闭勾选，可以在球正在移动时观察阻尼/碰撞变化。
- “记住这组”保存一组内存对照；改值后点“切换对照”，可以在当前/已记住两组之间来回切换。
- “恢复基线”恢复全部9项初始物理值，保留本局生命、升级和敌人；重开则清成长，但保留这次选好的物理基线。
- “复制参数”得到JSON，可直接粘贴给开发者；“保存参数”在EXE旁生成`handfeel_preset.json`，下次启动点“加载参数”恢复。编辑器运行时保存到Godot的user目录，界面显示实际路径。保存失败会提示，不冒充已经写盘。

## 参数与生效时机

| 参数 | 初始值/范围 | 生效 |
| --- | --- | --- |
| 发射冲量 | 1050；300～2200 | 下一次真实发射；拖拽比例和1500 px/s速度上限保持原规则 |
| 主球阻尼 | 0.12；0～2 | 当前运动即受影响，越大停得越快 |
| 球弹性 | 0.85；0～1 | 主球和现有/新伙伴的下一次接触 |
| 球摩擦 | 0.05；0～1 | 主球和伙伴的接触摩擦 |
| 敌人质量倍率 | 1；0.25～3 | 当前及新生成普通/重敌/炮台，不重建实体；普通0.2、重敌0.55乘倍率 |
| 撞敌续力保留 | 0.65；0～1 | 下一次有效撞敌；原0.6秒窗口和总预算仍保留 |
| 敌人受击硬直 | 0.65秒；0～1.5 | 下一次有效受击，不倒改正在计时的硬直 |
| 基础发射冷却 | 2.2秒；0.3～4 | 当局立即应用，已有恢复百分比保留，不赠送额外发射 |
| 抵消反向动量比例 | 0；0～1 | 下一次发射，越大越容易反向转向 |

发射冲量和阻尼是**成长前基线**。例如把冲量调为1400，取得一层大力后实际为1610；冷却也按本局升级比例继续下降。面板下方显示实际冲量、阻尼、冷却、敌人质量和当前速度，避免把基线误认成升级后的值。首领质量不跟普通敌人倍率变动。

## 文件、节点和数据流

`tuning_run.tscn`继承正式`run.tscn`，只新增两个节点：`LiveTuning`负责物理白名单，`TuningPanel`负责界面。原正式run和旧F5不引用调参入口。

1. `lab/tuning_panel.gd`根据9条参数声明生成滑杆和数字框，发出`parameter_requested(id, value)`。
2. `live_tuning.gd`拒绝未知/非有限值，限制范围，应用于当前对象；没有另写一套发射或伤害规则。
3. 当前主球继续通过`DemoLaunch`与真实冲量运动；不会因调参直接设置速度或位置。阻尼、材质和质量按Godot物理继续求解。
4. 每物理帧按“调参基线×正式构筑”同步，覆盖正式成长/重开从原值重算造成的回退；新敌人和伙伴也在此处接入。材质先复制为实例独享，不污染共享资源。
5. UI程序同步时不重复触发值变化，避免滑杆和数字框互相调用形成递归。

只在面板自己暂停了战斗时，收起才负责恢复；从原暂停菜单、选卡或结算打开面板，不会误解除别人的暂停。面板及按钮区域参与`over_controls()`判定，松鼠标不会误发射。改值也会取消已有拖拽。

## 修改与扩展

新增参数时在`DEFAULTS`和`SPECS`一起声明默认值、范围、步长、标签、用途；在`_apply_values()`明确映射到哪个现有规则，再补测试。比如发射冲量继续乘`build.launch_multiplier()`，不能另维护一个绕过成长的值。原快捷模式保留白名单；用户明确要求完整引擎量后，通用属性编辑放入独立完整模式，按元数据类型与生效时机处理，详见025。

面板位置、边框、滚动区和按钮容器可在`tuning_panel.tscn`检查器修改；参数行按声明动态生成。不要挤掉原有生命/冷却/奖励界面。推荐先在1280×720逻辑尺寸及实际较小窗口验证，再交策划。

## 验证与常见问题

运行`tests/roguelite_live_tuning.gd`，覆盖滑杆/数字实际接线、当前/新敌人物理、同局不重建、真实强冲量、成长/重开保持、冷却比例、暂停所有权、恢复/对照/存取及原入口隔离；完整验证入口和CI均接入。

实窗验收：启动EXE→调一项→F1收起→真实发射→F1再调→切换对照再发→保存/恢复/加载。试完把JSON交回；手感偏好仍由实际体验决定。

- 改冲量后正在飞的球没有突然加速：正常，冲量作用于下一次发射；阻尼可观察当前运动。
- 数字和实际值不同：检查是否拿了大力、滑行或冷却升级，看面板的实际读数。
- 开了面板球不动：默认暂停保护；关闭“调参时暂停战斗”即可边运行边调。
- 新敌人质量不同：质量倍率保留普通/重敌的基础比例，不把所有敌人改成同一质量。
- 保存失败：EXE所在目录可能不可写，界面会提示；可用“复制参数”直接交回。

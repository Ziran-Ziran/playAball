# 翻转板转速修复与逐项功能验证

## 问题和目标

玩家反馈翻转板稍碰便快速旋转。旧检查只确认“冲量能使板转动”和“轴心不脱离”，没有检查最大转速、限位和停转。真实主球碰撞复现中，中心板峰值10.2541弧度/秒，7秒后仍有7.6252弧度/秒，并转过配置的1.2弧度限位。偏心板也越界。

同版引擎的本地复现是修复依据；[Godot上游问题88481](https://github.com/godotengine/godot/issues/88481)也记录了PinJoint2D角度限制异常。该链接提供背景，不能替代本机测试。

## 文件、节点和输入到输出

`pivot_paddle.tscn`包含固定Anchor、动态Paddle和PinJoint2D。球撞Paddle产生真实碰撞冲量，Pin保住轴心；`pivot_body.gd`在物理积分接口里约束角速度和活动范围。没有用逐帧位置/旋转赋值播放假物理。

`pivot_paddle.gd`配置每个实例的初始角度、偏心轴和角度范围，并把“父节点世界角度＋实例初始角度”交给刚体作为基准。关闭异常的内置角度限制，仍保留PinJoint2D的真实轴心约束。

`pivot_body.gd`先处理显式复位，再限制转速；接近摆角边界时，把向外速度限制在下一物理步剩余角度内。接触求解可能在回调之后增加很小的越界，因此对越界量使用有上限的向内速度稳定边界，防止反复碰撞累计漂移。反向撞击仍能把板推离限位。

## 检查器调参

| 所在节点 | 参数 | 当前值/含义 |
| --- | --- | --- |
| Paddle刚体 | mass | 3→6，减小轻碰带来的角加速度 |
| Paddle刚体 | angular_damp | 1.4→2.6，加快自然停转 |
| Paddle脚本 | max_angular_speed | 1.2弧度/秒，约69度/秒 |
| 场景根节点 | initial_angle | 初始角度，限位围绕此角度而非世界零度 |
| 场景根节点 | pivot_offset | 局部轴心偏移，55表示偏心板 |
| 场景根节点 | angle_limit | 两侧最大摆角；0表示不限制角度，仍限制速度 |

修改质量或阻尼时，先用轻碰80、常规300和强碰1050三种主球速度检查；不能只调到“不动”。形状和轴心没有随这次调参变化。显式复位仍集中到`request_restore()`和`_integrate_forces()`，重开不继承旧转速。

## 复现和验证

使用本机实际的Godot4.7.1路径运行：

```powershell
& tools/verify.ps1 -GodotExe <本机Godot绝对路径>
```

单独运行两套新增测试：

```text
Godot --headless --fixed-fps 120 --path . --script tests/roguelite_paddle_response.gd
Godot --headless --fixed-fps 120 --path . --script tests/roguelite_feature_acceptance.gd
```

`paddle_response`用实际主球碰撞，覆盖两方向、中心/偏心轴、三种速度、旋转实例、旋转父节点、反复冲量达到限位、反向推回、停用和复位。原始结果写`.local/paddle_response.json`。`--fixed-fps 120`固定模拟步长并加速测试，不改变工程120Hz物理设置，不代表真人输入。

`feature_acceptance`在正式Game场景中，对15项普通Buff和强身兜底逐个寻找确定种子的合法候选，通过实际卡Button信号选择；检查动画结束后按钮可用、收益文案存在、等级只加一次、奖励被消费、战斗恢复。对动力、滑行剩余速度、冷却、双发、增员、跟随、回血、四卡、新生成敌人缩范围和生命上限检查实际效果。重型/补刀/保龄球/爆炸/接力/震退的命中效果及递归上限仍由独立`build`和`reward_effects`测试覆盖，避免把“等级变了”当作完整效果证明。

原有地图、传送、生命、敌人、白饭、商店、事件、胜负、菜单、设置和调试工具继续由各自行为套件验证。完整功能与证据对应见[本轮审查记录](../reviews/2026-11-03-function-verification.md)。人工窗口操作与引擎内输入分别记录；这些测试不能代替用户审美或自然通关验收。

常见错误：只限制绘图角度、仍让刚体高速旋转；把限位当世界角度；限位后禁止反向运动；反复推板产生累计漂移；测试只断言属性、不实际发射或等待效果；把未认可生图写为最终素材。

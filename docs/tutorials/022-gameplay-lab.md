# 022：B线玩法实验室

打开`scenes/roguelite/gameplay_lab.tscn`后按F6。它是独立开发入口，不替换正式`run.tscn`，不修改F5旧侧视，也不会把参数写回正式`.tres`或actor默认值。首版保持正常速度。

## 1. 八类夹具

| 键 | 夹具 | 当前用途 |
| --- | --- | --- |
| `1` | 单敌 | 指定类型/生命/距离/冲量，检查速度门槛、伤害和击退 |
| `2` | 怪群 | 固定生成1～8只同种敌人，观察推动、密集接触和配对冷却 |
| `3` | 墙角 | 安装固定L形墙，比较真实反弹与卡角 |
| `4` | 伙伴 | 指定1～4伙伴和跟随状态，观察待命/接力与实体障碍 |
| `5` | 范围 | 控制玩家与1～8个脆皮/重敌的距离，检查索敌、完整预警和离开取消 |
| `6` | 炮台 | 控制1～8个炮台的距离、范围和AI，检查预警、炮弹与独立飞行 |
| `7` | 分裂 | 使用正式RunDirector分裂规则生成4/6生命族根，观察两代预警和整族奖励 |
| `8` | 首领 | 实例化正式首领，可关闭AI只看站桩碰撞或打开完整阶段 |

快捷键只在实验室脚本中注册：`1～8`切夹具，`R`应用参数并重置，`T`固定发射，`L`显隐读数/日志，`Ctrl+S`保存预设，`Ctrl+O`加载。文本框正在编辑时以上游戏热键不触发。

数字框仍有焦点时，`R`不会触发。请点击“应用并重置”，或先点击场地空白再按`R`。实验室不进入正式胜负流程：玩家生命归零只显示“已倒下”，不会自动结束或切场景；按上述方式重置实验。正式胜负仍以`run.tscn`为准。

## 2. 参数白名单

面板不提供任意属性名输入框。所有值只来自以下声明字段，显示单位、正式基线提示和当前试验值：

| 参数 | 单位/值 | 默认 | 生效 |
| --- | --- | --- | --- |
| 敌人类型 | 脆皮/重敌/炮台 | 脆皮 | 重置重建 |
| 初始构筑 | 基础/机动/火力/伙伴/生存/节奏 | 基础 | 重置重建 |
| 敌人数量 | 个；作用于怪群、范围、炮台和伙伴夹具 | 3 | 重置重建 |
| 覆盖生命 | 点，0=种类默认 | 0 | 实体入树前 |
| 目标距离 | 像素 | 390 | 夹具重建 |
| 固定方向 | 度 | 0 | 下一次固定发射 |
| 固定力度 | % | 100 | 下一次固定发射 |
| 伤害速度门槛 | px/s | 180 | 重置重建 |
| 配对冷却 | 秒 | 0.18 | 重置重建 |
| 发射冷却 | 秒 | 2.2 | 重置重建 |
| 伙伴数量 | 个 | 1 | 重置重建 |
| 撞击续力保留 | % | 65 | 重置重建 |
| 攻击/索敌范围 | 像素 | 180 | 实体入树前 |
| 固定种子 | 整数 | 31030 | 重置重建 |
| 伙伴跟随 | 开/关 | 关 | 重置重建 |
| 击破分裂（仅夹具7） | 开/关 | 关 | 重置重建 |
| 敌人AI | 开/关 | 关 | 实体入树前 |

读数/日志显隐立即影响显示；“应用并重置”和`R`重建物理夹具。不要在测试中途改敌人参数再解读同一轮数据，重建会清旧实体、弹、攻击资格、统计和日志。

固定发射由`DemoLaunch.launch_with_drag()`进入与玩家拖拽相同的阻塞、冷却、双发、正式冲量与`DemoPlayer.launch()`；不直接写速度，也不绕过冷却。方向/力度只改变正式拖拽向量。

## 3. 读数与拒伤日志

实验面板显示：

- 实验时间和清场时间
- 初始构筑、发射链/代数、冷却/可用状态
- 玩家速度、最近真实接触速度和当时攻击资格
- 剩余撞击续力预算与剩余时间
- 有效命中、拒伤、实际伤害
- 当前敌人生命、危险弹和分裂预警
- 各拒伤原因计数

拒伤原因来自`DemoCombat.contact_outcome`与`DemoHealth.damage_rejected`的实际分支：没有攻击资格、速度不足、配对冷却、目标已死/不可伤、投射物重复或耗尽、玩家无敌/已倒下和敌人离开范围等。未知事件不会根据画面猜原因。

日志在内存中固定上限160条；长时间运行不会无限增长。实验室保留最近40条显示，并保留最多320行用于复现记录。

## 4. 预设和复现

保存预设写入`res://.local/gameplay_lab_preset.json`，内容含：

- schema版本
- 共同基线SHA
- 夹具ID
- 全部白名单参数
- 实际已应用参数
- 固定方向/力度及正式发射契约标记

加载先检查schema和基线，再经白名单重建；不一致会写日志。个人文件在`.local/`，已被Git忽略，不提交本机记录。需要跨电脑共享时，先抽取必要字段转成项目相对开发资源并经过Review。

“保存复现”写入`res://.local/gameplay_lab_report.txt`，包含Godot/平台版本、基线、参数、预期、结果摘要、步骤和最近日志。截图/录音、真人视觉或手感需另行记录，不能由文本自动生成。

## 5. 验证与扩展

```powershell
Godot --headless --path . --script tests/roguelite_gameplay_lab.gd
Godot --headless --path . --script tests/roguelite_presentation_interface.gd
./tools/verify.ps1 -GodotExe <本机Godot绝对路径>
```

实验室测试覆盖：独立入口、单敌固定发射真实伤害、怪群、重置清旧对象、八种夹具重建、范围/炮台边界与数量、分裂两代与整族奖励、构筑应用、预设加载、正式入口隔离、固定日志上限和输入框热键保护。52项通过是开发夹具证据，不是真人觉得手感好或完整通关。

首版未提供批量参数扫描、输入录像/回放、时间曲线和统计导出。新增参数时先证明它对应现有真实规则，加入白名单单位/范围/生效时机，再补实验测试；不要加入任意`set()`、全局作弊键或只对正式run有效的清场/无敌能力。

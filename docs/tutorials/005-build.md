# 本局构筑与碰撞升级

本功能让每次清波后的选择影响下一波的开球方式。一局开始只有一颗同伴、2.2 秒冷却，不跟随。`DemoBuild` 保存本局升级级数；重开清空，不写存档。

## 文件与输入到输出

- `scripts/roguelite/upgrade_definition.gd` 定义卡片资源：`id` 是程序匹配键，`title`、`description` 是界面文字，`max_level=0` 表示可重复。
- `resources/roguelite/upgrades/` 的八个 `.tres` 是可在检查器打开的卡片。
- `scripts/roguelite/run_build.gd` 保存 `levels`，生成候选并检查上限；`companion_count()` 和 `launch_cooldown()` 提供派生参数。
- `scripts/roguelite/collision_combat.gd` 消费构筑，统一处理碰撞与升级收益。
- 竞技场持有一个构筑，将它赋给 `combat.build`；清波时传入随机数发生器、是否第一波及当前/最大生命，调用 `candidates()`。选择后调用 `choose(id)`；成功才更新同伴数量、冷却、跟随或恢复生命。

卡片选择和节点操作分开：`choose("heal")` 只记录选择，竞技场恢复两格并限制到最大生命；否则容易恢复两次。跟随由竞技场根据 `levels.get("follow", 0)>0` 交给同伴管理器，不在战斗解析里移动同伴。

## 候选与等级

第一轮保证新同伴；其余从合法池随机抽取，不重复。新同伴最多三级，总数四；快速上弦最多两级，冷却依次 1.95、1.7 秒。跟随、重击、接力、保龄球、碰撞爆破各一级。满级卡移出池，满血隐藏恢复；池全部耗尽时只返回一张恢复兜底，不复制卡片填三槽。固定随机种子只固定抽卡，物理轨迹不承诺跨机器一致。

`reset_build()` 清空等级。竞技场重开还须重新应用基础同伴数、冷却和跟随关闭，并调用 `reset_combat()`，否则旧发射的爆破标记、配对冷却和统计可能残留。

## 有效撞击后才给予收益

基础先按接触法线接近速度计算档位，小于 180 无伤，180/450/850 对应 1/2/3 伤害。先通过有效速度与同对 0.18 秒去重，才处理升级：

1. 重击只对主球在基础伤害上加一，不把低速蹭动变成有效伤害。
2. 接力仍保留传感器的一次基础传能；只有小兵撞出小兵时再加一次补偿，最多 262.5 冲量。同一接收球、同一发射链只能获得一次，三代上限仍生效。主球交接和出击球之间的实体碰撞不额外补偿。
3. 保龄球在主球/出击小兵有效击退存活敌人时调用敌人 `make_projectile(chain)`；敌人自行维护 0.6 秒窗口与两次预算。战斗解析额外保证最多伤两名不同敌人；敌人投射物不能赋予下一代资格，也不能击出待命小兵。
4. 碰撞爆破在同一发射链首个小兵有效命中时，遍历 `demo_damageable` 组，对距接触点不超过 80 的存活目标额外伤害一。直接调用 `hurt()`，不再次进入碰撞解析，所以不递归、不制造保龄球。若首个目标仍存活，它也受到额外伤害。

动态敌人和首领加入 `demo_damageable` 组，提供 `dead`、`hurt(amount)`；静态 `DemoTarget` 的直接碰撞保持兼容，想受到范围爆破也须入组。首领若提供 `hurt_at(amount, point)`，直接撞击优先按接触位置处理模块；爆破调用普通 `hurt()`。击退使用一次有限冲量，正常运动由刚体物理处理。

## 如何调参与扩展

在 Godot 文件系统打开八个资源，可编辑文字和等级上限。数量、冷却下限与战斗机制目前是脚本规则：改变等级上限时须同步 `companion_count()`、`launch_cooldown()` 的数值，不能只让界面显示更多级。速度阈值、配对冷却和接力代数在 Combat 节点检查器调整；爆破半径、补偿上限在战斗脚本中修改并同步测试和设计。

添加升级时先写候选/上限与实际收益检查，再增加资源、注册 `UPGRADE_IDS`，最后在负责该行为的模块消费。不要在卡片脚本里直接访问竞技场或生成刚体。

## 复现、验证和常见错误

确认当前设备 Godot 4.7.1 stable 路径后运行 `--headless --path . --script tests/roguelite_build.gd`。测试覆盖基础构筑、上限、首轮保底、候选去重、满血/空池、重开清空、动态敌人伤害、重击低速无效、保龄球上限与不传代、爆破半径/每链一次、接力补偿与三代上限。这是自动规则验证，不能代替真实窗口手感和平衡试玩。

人工操作：清完第一波观察新同伴选项；分别选择同伴、跟随和冷却，观察数量/散落归队/能量恢复变化；获得重击或爆破后比较有效开球与低速贴靠；重开确认恢复一颗同伴、无跟随、基础冷却。保龄球观察被撞存活敌人在短窗内撞到其他敌人，且连锁不能无限传代。

常见错误：同一接触双方都扣血（应统一接 combat）；范围爆破漏掉目标（检查分组）；恢复两次（构筑不直接治疗）；重开仍爆破或少爆破（检查战斗重置）；升级后小兵穿墙（跟随沿用刚体限力引导与障碍碰撞，不用直接改坐标）。

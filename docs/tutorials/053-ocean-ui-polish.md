## 文件、节点与数据流

- `scripts/ui/ocean_ui.gd`：共享图片九宫格主题、音量行与百分比、按钮反馈绑定、面板显现、减少动态偏好。字体主题复用，避免重建时释放仍在布局的字体。
- `scripts/ui/ocean_motion.gd`：读取内置生图4列2行图集，8fps播放；或为按钮提供颜色反馈。所有装饰鼠标穿透，不移动命中区域。
- `assets/ui/ocean_polish/`：生成面板、按钮透明母图与裁切缩小版、小鱼图集；生成提示与加工方法见SOURCE。新增图像及帧内容均来自内置image_gen，没有改用其他生图服务。
- `main_menu.gd`：运行时SettingsPanel和SettingsScrim、真实音量控件、返回与角色阻断。
- `game.gd`：保留HUD/Menu/Buttons既有操作路径，设置分组与PauseScrim，仍调用原暂停/重开/返回逻辑。
- `sea_ui_theme.gd`、`run_hud.gd`、`rest_panel.gd`：统一各弹窗皮肤；伤害、成长、经济和生成仍由原玩法校验。
- `card_flow.gd`：减少动态时停止流光，静态显示原卡图。

音量拖动 → 实际音频设置 → 百分比；外部音乐变化仍用原mix_changed同步控件。打开设置 → 遮罩显示、导航禁用、角色阻断、焦点给主音量 → 180ms淡入；关闭立即恢复导航。设置即时保存，返回不额外修改数值。图集播放与120ms按钮渐变由Godot驱动，生图提供帧内容和底图，不生成文字、价格或物理状态。

小鱼由非Control的OceanBadge持有Sprite子节点，避免PanelContainer把装饰拉满面板。面板只淡入透明度，按钮只改变颜色，不缩放Container内坐标。暂停期间UI动画继续；“减少动态效果”固定小鱼首帧、禁用淡入和卡片入场、停止卡框流光，角色也走原减少动态接口。

## 修改与扩展

图片使用九宫格：面板边距44px、内容36px；按钮横向切片56px、竖向12px。不要用含文字的整张UI截图代替皮肤。主菜单SettingsPanel由代码创建，需在运行后的Remote树调试；持久调整改_build_settings、_layout_settings默认值。生成图片的切片边距在OceanUi.panel_style/button_style调整；图集速度和84×86装饰尺寸在ocean_motion调整。

新音量项用volume_row创建，给真实设置回调；不可只改变标签。新操作仍从玩法提供enabled和回调，不在表现层扣币。商店自动换行先明确detail真实宽度、更新最小尺寸，再计算整个面板高度；不能先按零宽测高。奖励卡宽按实际StyleBox内容边距计算，不能写死旧边距。更换图集必须保持4×2同格注册；需要不同格数时同步改帧索引和测试。

## 验证与常见错误

用实际核实的Godot4.7.1路径执行 `tools/verify.ps1 -GodotExe <路径>`，已包含 `tests/ocean_ui.gd`；远端CI同步入口但需授权上传后才会运行。建议把APPDATA隔离到.local临时目录，避免个人静音偏好影响音效测试；测试本身还原设置文件。

专项覆盖1280×720和1024×576设置/暂停范围、关闭恢复输入、主音量真实值和百分比、图集播放/冻结、减少动态时卡片立即可点。另复验既有music_manager、卡片内容流和正式游戏交互；原生截图核对两种尺寸的设置/暂停/奖励/补给/结果，检查边框、文字、禁用状态、焦点不重叠。原生菜单动作166项回归0失败，输出与头顶/脸颊等新截图另存本批actions目录，没有覆盖旧证据。完整测试结果记STATUS。

常见错误：透明母图四周可能含极低alpha噪点，直接getbbox会保留巨大空边，本次按alpha>80确定按钮裁切边界；切图不等于重画。装饰不能作为PanelContainer直接Control子节点，否则会被布局铺满。首次自动换行需要两帧稳定后收紧设置页高度。不要把截图或脚本状态验证写成人工通关；未进行导出包和跨平台审美验收。

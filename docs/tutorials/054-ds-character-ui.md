## 文件、节点与输入输出

- `assets/ui/ds_console/`：人物八帧、浅色面板、按钮母图/切图、去动物版菜单房间。SOURCE与generation.json保存内置生图完整提示词、参考和当前指纹；没有下载网页图作为生产素材。
- `main_menu.gd`：SettingsPanel/Columns下的CharacterColumn与Preferences；人物独立Control，不拦截输入，真实HSlider和CheckButton继续调用原设置接口。宽880，按视口留64边距收缩；高度至少500，字体布局稳定后再收紧。
- `ocean_ui.gd`：面板18px九宫格、32px内容边距，按钮28px横/10px纵切片；主按钮实色、次按钮低透明度，深蓝真实文字、蓝色键盘焦点。
- `ocean_motion.gd`：同一DS人物图集按4×2切片。3.8秒周期先静候2秒，再以八帧做1.8秒轻回应；不再一秒循环点头。减少动态时固定0帧。
- `game.gd`：暂停Buttons改为GridContainer：左侧保留Resume/Reset/Home，右侧Mute/Shake/Split与Volumes；保留原按钮对象、稳定节点路径、已连接玩法信号。底部DS人物与文案独立，不占点击区域。音量同步改为递归查找MusicVolume。
- `run_hud.gd`：浅色主题只施加于奖励/结果Panel，不施加整个Overlay，防止深色生命面板继承深蓝字。Game按所有模态显示状态统一隐藏/恢复世界HUD，避免高z_index金币/状态绘制到弹窗前。
- `upgrade_card.tscn`与card_flow：保留真实内容流和原插画，仅将框/字体改为蓝白，流光改蓝且保持减少动态。

输入仍为控件请求→原玩法校验→真实状态刷新。没有修改伤害、经济、物理、卡池或碰撞。设置打开继续阻断菜单背后导航和角色互动，关闭恢复原输入与焦点。人物服装、眨眼图像来自内置生图，Godot只负责取帧与播放节奏。

## 怎样调整和扩展

Remote树中SettingsPanel/Columns可检查双栏和人物尺寸；永久改main_menu默认值。Pause的Grid保留Buttons/Resume等路径，新增按钮先考虑左右配对，音量项放Volumes。不要重新把普通鱼贴纸放回标题角落；需要鱼相关元素时先核对AGENTS、已认可人物参考及本页来源。

更换图集保持4×2等格注册，在ocean_motion中调整220×300正文尺寸和静候/回应时序。修改主题只施加弹窗，战斗深底HUD单独保留字体色。改卡框边距后按StyleBox真实最小尺寸算卡宽，并检查四卡和长说明。

## 验证与常见错误

执行 `tools/verify.ps1 -GodotExe <当前机器已核实的4.7.1路径>`；个人静音偏好可能影响音效回归，测试APPDATA隔离到.local并在结束后恢复环境变量。ocean_ui专项覆盖两种窗口、DS图集绑定、完整人物分栏、真实音量、减少动态、四卡边距、深色HUD文字和模态HUD隐藏/恢复；身份画得是否正确仍需人工看图，路径检查不代替识图。

同时运行原生菜单点击动作、实际鼠标Resume/商店购买/禁止复购/重开，复核分栏后节点与信号没有损坏。完整新鲜证据见STATUS；未做自然完整通关、导出包验证或远端CI。

常见错误：只改小鱼文件名而画面仍是动物；把浅色主题施加到所有HUD；z_index更高的状态标签压过模态面板；用整个生图当交互页面；把测试通过直接换成8分美术；角色八帧等速反复点头。这些都必须分别检查。

# 实际伙伴身份卡面

三张图均于2026-11-10使用内置image_gen重新生成，原图保留在上级目录用于历史对照。完整提示、参考、实际尺寸和SHA256见[generation.json](generation.json)。

生产索引只替换`companion`的三个等级；28张卡的等级结构、规则和玩法均不由插画决定。保留原始PNG，运行导入上限512并开启mipmap，降低显存占用；最终卡片小尺寸观感需实机截图核对。

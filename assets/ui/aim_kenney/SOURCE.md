# Kenney瞄准素材来源

作者：Kenney Vleugels（Kenney.nl）。官方页面核查日期：2026-11-05。

- [Cursor Pack](https://kenney.nl/assets/cursor-pack)：官方页面标注180个素材、Creative Commons CC0。本工程选用Basic/Double的pointer_toon_a与navigation_e；公开镜像为[shorepine/kenney](https://github.com/shorepine/kenney/tree/3694c6879e487c108f55677be7dd2ca75b07cc3b/ui/Cursor%20Pack)。镜像目录未提供独立许可文件，因此这里如实记录官方许可页面，不将粒子包许可冒称为Cursor Pack的原始文件。
- [Particle Pack](https://kenney.nl/assets/particle-pack)：官方页面标注80个512×512素材、Creative Commons CC0。trace_06与light_03来自[Calinou的Godot预打包镜像](https://github.com/Calinou/kenney-particle-pack/tree/ab7086639ee73be31abd87feb21bf1402d4e8144)；原包的作者/CC0说明保存在KENNEY_PARTICLE_LICENSE.txt。

逐文件固定版本URL和SHA256见sources.json。原始PNG没有重绘；游戏只进行旋转、等比缩放、颜色/透明度调制。用户明确要求箭头上网找成熟素材，这一要求覆盖之前角色图片“内置生图”的范围；七张角色球仍全部由内置imagegen生成。

采用单体圆角箭头及低透明尾流。五个重复小V已被用户否定并撤下。导航箭头是可切换的对照候选，当前两版技术验证不代表用户审美认可。没有下载整包插件、执行远程代码、付款或注册账号。
